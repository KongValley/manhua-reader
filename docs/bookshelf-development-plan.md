## 1. 目标与范围

### 1.1 产品目标

为本地漫画建立一个「打开就能继续看」的个人书架：

1. 用户能把手机/平板上的 PDF、MOBI 漫画导入应用。
2. 书架用封面网格展示书籍、格式、页数和阅读进度。
3. 点击书籍直接回到上次阅读页；阅读进度可靠持久化。
4. 大文件（100MB 级）导入、浏览、删除都不能阻塞界面。
5. 手机与平板自适应；删除只影响应用内副本，不碰原文件。
6. 书架数据全部本地化，无账号、无联网依赖。

### 1.2 非目标（本阶段不做）

- 在线书城、账号体系、云同步。
- 自动下载/订阅/爬虫。
- 多人共享书架、社交评论。
- 对 DRM 内容或纯文字 MOBI 的破解/排版阅读。

### 1.3 约束

- Flutter 3.47+，移动端与 Windows 共用一套书架代码。
- 文件系统使用 `path_provider` 的应用私有目录。
- PDF 通过 pdfrx/PDFium 解析；MOBI 使用项目内解析器。
- 不引入服务端；书架状态以本地 JSON 为准。
- 公开仓库不提交用户提供的版权漫画样本。

### 1.4 成功指标

| 指标 | 目标 |
| --- | --- |
| 首次导入 1 本 100MB 漫画 | 有进度反馈，界面可响应，无 ANR |
| 100 本书架冷启动 | ≤ 500ms 展示首屏，封面懒加载 |
| 从点击封面到打开阅读器 | ≤ 800ms（不含大文件首次解析） |
| 阅读进度丢失率 | 正常退出/切后台为 0；异常杀进程 ≤ 1 页 |
| 删除书籍 | 1 次确认，删除副本与封面，原文件不变 |
| 书架布局 | 手机 2 列、平板 4–6 列，无溢出 |

## 4. 交互与界面

### 4.1 页面状态机

```
loading ──► empty ──导入成功──► populated
   │           │                   │
   └─错误──────┴─导入失败──────────┘
populated ──导入中──► importing（覆盖层）
populated ──删除/重命名/搜索──► populated
```

- **loading**：骨架屏或轻量 spinner，避免白屏。
- **empty**：图标插画 + 一句话说明 + 「导入漫画」主按钮。
- **populated**：继续阅读卡片 + 「我的书架 N」+ 封面网格 + 右下角导入 FAB。
- **importing**：半透明遮罩 + 当前文件、总进度、百分比；禁止误触底层操作，支持失败汇总。
- **error**：SnackBar（单本失败）/ 对话框（多本失败汇总），不丢失已有书架状态。

### 4.2 布局

```
┌──────────────────────────────────────┐
│ [漫] 漫阅  PDF·MOBI              [i] │  ← 品牌 + 导入/信息
│                                      │
│ [封面]  ● 继续阅读                   │  ← 最近阅读卡片
│         书名                         │
│         ─────────── 第 12/196 页     │
│                                      │
│ 我的书架 (12)                        │
│ ┌────┐ ┌────┐ ┌────┐ ┌────┐          │
│ │封面│ │封面│ │封面│ │封面│          │
│ └────┘ └────┘ └────┘ └────┘          │
│  书名   书名   书名   书名            │
│  进度   进度   进度   进度            │
│                              [+ 导入]│
└──────────────────────────────────────┘
```

响应式规则：

| 可用宽度 | 列数 |
| --- | --- |
| < 520 | 2 |
| 520–699 | 3 |
| 700–939 | 4 |
| 940–1179 | 5 |
| ≥ 1180 | 6 |

卡片结构：

- 封面：比例约 0.7（宽/高），圆角、懒加载、失败占位。
- 顶部左侧：格式徽标（PDF / MOBI）。
- 顶部右侧：更多按钮（长按也可打开）。
- 封面底部：阅读进度条。
- 封面下：单行标题 + 页数/进度/未读状态。

### 4.3 书籍操作

- **单击**：打开阅读器；成功打开后更新最近阅读并置于列表前部。
- **长按 / 更多**：底部操作面板：继续阅读、编辑名称（P1）、删除。
- **删除**：对话框说明「只删除应用内副本，不影响原文件」；确认后删除副本与封面。
- **多选（P1）**：长按进入选择模式，顶部显示「已选 N 本」，支持全选、批量删除。

### 4.4 导入流程交互

1. 点击导入 → 系统文件选择器（多选，限制 PDF/MOBI）。
2. 关闭选择器后进入导入覆盖层，逐个处理。
3. 每个文件显示：正在复制 / 正在解析 / 正在生成封面 / 导入完成。
4. 加密 PDF 在解析阶段弹出密码框；错误密码提示重试；取消则该文件失败。
5. 全部结束后：成功 SnackBar；失败弹出汇总，列出「文件名：原因」。
6. 单本失败不影响其他文件；已成功导入的保留。

### 4.5 可访问性与桌面

- 所有图标按钮提供 tooltip；触控目标 ≥ 40×40。
- 深色主题，对比度满足阅读环境；不以颜色作为唯一状态提示。
- Windows 支持鼠标悬停、滚轮滚动；P2 支持拖拽文件导入。

## 5. 技术方案

### 5.1 分层架构

```
LibraryScreen (UI / 交互)
        │ 监听
        ▼
LibraryRepository (ChangeNotifier：书架状态、导入、删除、进度、持久化)
        │
        ├── AppPaths               应用目录（books / covers / library.json）
        ├── Import pipeline        复制、解析、封面、回滚
        ├── CoverGenerator         PDF / MOBI 首页 → 520px PNG
        ├── PdfPasswordCache       会话级密码缓存（仅内存）
        └── ComicSourceFactory     阅读时打开 PDF / MOBI
```

原则：

- UI 不直接操作文件系统，只通过 Repository。
- Repository 负责内存状态与落盘的一致性；导入过程中不让 UI 处于半状态。
- 封面生成、MOBI 解析、密码输入都属于可失败步骤，失败必须可回滚。

### 5.2 模块职责

| 模块 | 职责 |
| --- | --- |
| `library_screen.dart` | 页面布局、导入交互、书籍操作、删除确认、导入进度覆盖层 |
| `library_repository.dart` | 书籍列表、导入流水线、重复检测、删除、进度、书签、设置、JSON 落盘 |
| `app_paths.dart` | 应用根目录以及 `books/`、`covers/`、`cache/`、`library.json` |
| `cover_generator.dart` | PDF 首页渲染、MOBI 图片缩放、PNG 封面写入 |
| `comic_book.dart` | 书籍模型、序列化、进度、书签、页面数 |
| `pdf_password_cache.dart` | 会话级 PDF 密码内存缓存，不落盘 |
| `comic_source_factory.dart` | 阅读器打开 PDF/MOBI；加密 PDF 密码 provider |
| `file_picker` | 平台文件选择；Android SAF 返回流，无本地路径时走 importStream |

### 5.3 数据模型

`library.json` 结构（当前为 `version: 4`）：

```json
{
  "version": 4,
  "settings": {
    "mode": "horizontal",
    "rightToLeft": false,
    "doublePage": false
  },
  "library": {
    "view": "grid",
    "sort": "recentRead"
  },
  "stats": {
    "dailyPages": {
      "2026-11-20": 42
    }
  },
  "folders": [
    {
      "id": "folder-a",
      "name": "合集A",
      "createdAt": "2026-11-21T00:00:00.000"
    }
  ],
  "books": [
    {
      "id": "m3k2x9abc",
      "title": "VOL.001",
      "originalName": "VOL.001.pdf",
      "filePath": "C:/Users/.../ManhuaReader/books/m3k2x9abc.pdf",
      "format": "pdf",
      "pageCount": 196,
      "fileSize": 93803415,
      "addedAt": "2026-11-20T13:40:00.000",
      "lastPage": 3,
      "lastReadAt": "2026-11-20T22:49:00.000",
      "coverPath": "C:/Users/.../ManhuaReader/covers/m3k2x9abc.png",
      "favorite": true,
      "pinned": false,
      "series": "VOL",
      "folderId": "folder-a",
      "tags": ["单行本", "收藏"],
      "customCover": false,
      "bookmarks": [
        {
          "page": 1,
          "createdAt": "2026-11-20T22:49:00.000",
          "label": "封面与扉页",
          "note": "单行本封面与版权页"
        }
      ]
    }
  ]
}
```

设计说明：

- `id`：时间戳 + 随机数生成；文件名使用 `id.ext`，避免用户文件名冲突/非法字符。
- `filePath` / `coverPath`：应用私有目录绝对路径；加载时若失效，按 basename 在当前目录修复。
- `pageCount`：导入时解析；打开阅读器时若实际页数不同则更新并清理越界书签。
- `lastPage`：0-based；`progress = (lastPage + 1) / pageCount`。
- `bookmarks`：按页排序；名称/备注可空；随 JSON 保存。
- `favorite` / `pinned`：收藏与置顶；`pinned` 参与书架排序。
- `series` / `tags`：系列名与标签；v2 → v3 迁移时从标题推导系列提示。
- `folderId` / `folders`：书架文件夹；导入目录时创建或复用同名文件夹，删除文件夹只清空 `folderId`。v3 → v4 迁移允许空文件夹列表。
- `customCover`：封面是否来自用户图片；重新生成封面时复位。
- `stats.dailyPages`：本地日期 `yyyy-MM-dd` → 前进翻页数；最多保留 730 天。
- `version`：用于迁移；读取未知版本时保留原文件并回退默认值。

### 5.4 存储布局

```
<ApplicationSupport>/ManhuaReader/
├─ books/     <id>.<pdf|mobi>
├─ covers/    <id>.png
├─ cache/     预留：临时导入、封面重建
└─ library.json
```

- 书籍与封面使用稳定 ID，不依赖用户原始文件名。
- 导入先写 `books/<id>.part`，成功后 rename 为最终文件（P1 改进）。
- 删除书籍时：先更新列表并落盘，再尽力删除副本/封面；删除失败只记日志，不阻塞 UI。

### 5.5 导入流水线

| 步骤 | 动作 | 失败处理 |
| --- | --- | --- |
| 1 | 选择文件（多选） | 取消：直接返回 |
| 2 | 校验扩展名 | 非 PDF/MOBI：跳过并记错误 |
| 3 | 重复检测（原名 + 大小） | 已存在：记「已导入」并跳过 |
| 4 | 流式复制到 `books/<id>.part`，按 120ms 节流上报 | 失败：删除 `.part`，记录错误 |
| 5 | rename 为最终文件 | 失败：删除临时文件 |
| 6 | 解析页数/标题/封面 | 失败：删除副本与封面，记录错误 |
| 7 | 插入模型、原子保存 JSON、通知 UI | 保存失败：回滚内存插入并清理文件 |
| 8 | 汇总成功/失败 | 失败列表弹出对话框 |

关键点：

- **不整文件读入内存**：复制使用流；MOBI 只读取记录表与页面头部；PDF 通过 PDFium 按需读取。
- **进度**：复制占约 78%，解析/封面约 22%；多文件按「已完成 + 当前进度」计算总进度。
- **加密 PDF**：第 6 步使用异步 `PdfPasswordProvider` 弹密码框；取消/失败走第 6 步回滚。
- **并发**：当前顺序导入；P1 可抽象导入队列，仍保持单任务写文件，避免磁盘/内存峰值。
- **取消**：P1 支持取消剩余任务；当前至少保证单本失败不污染书架。

### 5.6 封面生成

- PDF：渲染第 1 页，目标宽 520px，PNG；白色背景。
- MOBI：读取第 1 个阅读顺序图片，使用 `instantiateImageCodec` 缩放到目标宽，PNG。
- 失败：`coverPath = null`，UI 用按书名字母/渐变生成的占位封面。
- P1：增加「重新生成封面」与封面缓存清理；记录 `coverVersion` 以便样本解析规则升级后重建。

### 5.7 持久化、迁移与恢复

- 写入：先写 `library.json.tmp`，flush 后 rename 为 `library.json`；失败时回退直接写并清理临时文件。
- 频率：进度/书签/设置变更做 450ms 去抖；退出阅读器、应用进入后台、导入/删除后强制 flush。
- 并发：Repository 内串行化写入（`_saving` + `_dirty`），避免并发覆盖。
- 损坏：JSON 解析失败时回退空库并保留原文件；P1 增加 `library.json.bak` 与「恢复备份」提示。
- 迁移：读取 `version`，逐版本迁移；未知版本先备份再尝试读取。
- 路径迁移：iOS 容器 UUID 变化时，按 `basename(filePath)` 在 `books/`、`covers/` 重新定位；失败则标记「文件丢失」。

### 5.8 与阅读器/书签联动

- 打开书籍：检查文件存在 → 打开阅读器 → 成功后 `updateProgress`，将书籍移到列表前部。
- 阅读器翻页：更新 `lastPage/lastReadAt`（内存），450ms 去抖落盘；退出/切后台 flush。
- 书签：书架不直接展示书签内容，但计数/名称可在操作面板显示（P1）；书签变化由 Repository 统一持久化。
- 页数变化：打开时校正 `pageCount`，删除越界书签，避免进度/跳页异常。

### 5.9 性能与并发

- 封面：文件 PNG + `Image.file` + 系统图片缓存；封面目标宽 520px，避免原图解码。
- 网格：`SliverGrid` 懒构建；滚动时不解析书籍内容。
- 大文件：复制/解析均在异步 I/O 或原生线程；主 isolate 只做轻量状态更新。
- 内存：不缓存整本漫画；MOBI 页面按需读取；PDF 由 PDFium 按页渲染。
- 批量导入：顺序处理，限制峰值内存；每本完成即落盘。
- 目标：100 本书冷启动首屏 ≤500ms；100MB 导入期间 UI 持续响应。

### 5.10 错误分类与提示

| 错误 | 用户提示 | 处理 |
| --- | --- | --- |
| 不支持格式 | 仅支持 PDF/MOBI | 跳过该文件 |
| 文件不存在/权限 | 文件不存在或无法读取 | 跳过 |
| 重复导入 | 已在书架中 | 跳过 |
| 加密 PDF 取消 | 已取消输入密码 | 回滚 |
| 密码错误 | 密码不正确，请重试 | 重新弹框 |
| DRM/纯文字 MOBI | 不支持该 MOBI | 回滚 + 说明 |
| 损坏 PDF | 无法打开 PDF | 回滚 |
| 磁盘空间不足 | 存储空间不足 | 回滚 + 提示清理 |
| 封面失败 | 不失败导入 | 占位封面 |
| JSON 损坏 | 书架数据损坏 | 回退空库/备份 |

错误信息不包含密码；密码仅存在于内存与 PDFium 调用参数中。

## 9. 风险与对策

| 风险 | 影响 | 对策 |
| --- | --- | --- |
| 100MB 文件复制/解析慢 | 用户以为卡死 | 流式复制 + 进度 + 禁用重复操作；必要时后台 isolate/原生解压 |
| Android SAF 无本地路径 | 导入失败 | 走 `importStream`，不依赖 path；失败提示具体原因 |
| iOS 应用容器路径变化 | 书架文件失效 | 按 basename 自动迁移；失败提供重定位 |
| PDFium/MOBI 解析异常 | 导入或打开失败 | 回滚 + 错误分类；封面失败不阻塞导入 |
| 加密 PDF 密码策略 | 密码泄露/重复输入 | 仅内存缓存、不落盘；删除书籍清缓存；产品说明清楚 |
| JSON 损坏/写中断 | 书架丢失 | 临时文件 + rename、去抖、备份/恢复（P1） |
| 重复检测误判 | 两本同名同大小不同内容 | P1 改用内容哈希（如快速 xxHash/SHA-1 前若干 MB） |
| 版权样本入公开仓库 | 法律/体积 | `.gitignore` 排除用户样本与截图；README 说明 |
| 书架过大（>1000 本） | JSON/首屏变慢 | 已加入 `LibraryIndex` 增量索引；>1000 本时再迁移 SQLite/Isar + 分页 |

## 12. 关键设计决策记录

| 决策 | 选择 | 原因 |
| --- | --- | --- |
| 原文件 vs 副本 | 复制到应用目录 | 避免 SAF 临时授权失效、文件被移动；删除不影响原文件 |
| 持久化 | JSON 单文件 | 数百本规模足够、易调试；过千本再迁移数据库 |
| 封面 | 独立 PNG 文件 | 避免每次启动渲染 PDF/MOBI；可用系统图片缓存 |
| 导入策略 | 顺序队列 | 控制内存/磁盘峰值；实现简单可靠 |
| 进度写入 | 去抖 + 退出 flush | 减少磁盘写，兼顾异常安全 |
| 密码 | 会话内存缓存 | 避免明文落盘；安全与便利折中 |
| 章节 | PDF outline / MOBI HTML 标题 | 不引入重型解析；无章节时页码目录回退 |
| 大文件解析 | 按需读取，不整本加载 | 100MB 级漫画在移动端可用 |
